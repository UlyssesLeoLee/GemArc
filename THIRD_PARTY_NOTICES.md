## Known advisory on the pinned Vite

`vite@7.1.10` carries a high-severity advisory group (`server.fs.deny` bypass and
related dev-server issues — GHSA-93m4-6634-74q7 and others). The upstream fix is
`vite@7.3.7`, outside the current exact pin, so `npm audit fix --force` will not apply
it without changing the declared version. This affects the **dev server only** — it is
not in the produced static bundle. Decide deliberately: either move the pin to 7.3.7
or record an accepted-risk note here.

## Vendoring and distribution

The distributed plugin source archive **does not vendor** the npm packages or contain a
compiled WebGL bundle. `npm install` and `npm run build` must complete on a machine with
npm registry access or a usable local npm cache before obtaining a self-contained static
deployment directory.

`package-lock.json` is generated by npm during install and is not checked in; the exact
transitive versions above were read from a real install performed on this repository.
