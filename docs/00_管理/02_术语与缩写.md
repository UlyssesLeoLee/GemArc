# 术语表（中文/日文/英文）

> 文档编号：CTRL-002 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

| 中文 | 日文术语 | 英文 | 项目采用含义 |
|---|---|---|---|
| 要件定义 | 要件定義 | Requirements definition | 约定业务目标、功能、非功能与验收边界 |
| 基本设计 | 基本設計／外部設計 | Basic/External Design | 系统分解、接口、数据概念、UI及环境 |
| 详细设计 | 詳細設計／内部設計 | Detailed/Internal Design | 内部数据结构、算法、错误及实现契约 |
| 单元测试 | 単体テスト | UT | 最小可验证模块的接口与分支行为 |
| 集成测试 | 結合テスト | IT | 模块间、端到端契约与依赖组合 |
| 系统测试 | システムテスト | ST | 系统级业务/质量目标验证 |
| 验收测试 | 受入テスト | UAT | 需求方根据验收标准签核 |
| 非功能要求 | 非機能要求 | NFR | 性能、安全、可用、维护、迁移及环境 |
| 事实模型 | 統一アーキテクチャモデル | Architecture Model | 唯一模型，独立于渲染器 |
| 架构视点 | アーキテクチャビューポイント | Viewpoint | 规定关注点、约束与建模规则 |
| 架构视图 | アーキテクチャビュー | View | 模型对某一关注点的表达 |
| 因果干预 | 因果介入 | Intervention | 在声明的规则内改变输入/模块以推导结果 |
| 组件注册中心 | コンポーネントレジストリ | Component Registry | 带版本、Schema、License 的复用资产索引 |
| 构建锁文件 | ロックファイル | Lock Manifest | 保证模板/运行依赖版本不漂移 |
| 证据状态 | 根拠状態 | Evidence State | confirmed/assumed/illustrative/unknown |

**维度**：0D=存在（无独立页面）；1D=文本；2D=平面图与原型；3D=空间；4D=动态；5D=组合因果。此“D”是 GemArc 产品层级，不是数学上 5 条坐标轴。
