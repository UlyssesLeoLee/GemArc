## 正式参考（只引用，不全文再分发）

1. IPA《共通フレーム2013》出版页：https://www.ipa.go.jp/publish/secbooks20130304.html ；用于覆盖企划、要件、系统/软件开发、验证、运维保守、裁剪。
2. IPA 国际标准 SLCP：https://www.ipa.go.jp/digital/kaihatsu/slcp/index.html ；提示与现行 JIS X 0160:2021、JIS X 0170:2025 的关系。
3. IPA《非機能要求グレード2018》：https://www.ipa.go.jp/archive/digital/iot-en-ci/jyouryuu/hikinou/ent03-b.html ；六大分类为可用性、性能扩展、运维保守、迁移、安全、系统环境/环保。
4. ISO/IEC/IEEE 42010:2022 官方介绍：https://www.iso.org/standard/74393.html ；用于记录系统关注主体、利益相关者、关注点、视点与模型。
5. MCP 正式规范（2026-07-28）：https://modelcontextprotocol.io/specification/2026-07-28 及 GitHub 官方文档 https://github.com/modelcontextprotocol/modelcontextprotocol/tree/main/docs/specification/2026-07-28 。
6. GemArc 仓库：https://github.com/UlyssesLeoLee/GemArc 。
