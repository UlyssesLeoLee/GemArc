## 2. 质量目标量测基线

- 环境采集：CPU、内存、系统、浏览器版本、WebGL、模型节点/边规模、构建模式、Agent 与模型版本。
- Token 对照：固定输入仓库、同功能点和同交付物；分别统计“重写代码”和“脚手架复用”的输出 Token；至少 5 次测量取中位数，保留原始日志。
- 可靠性：构建失败不得更新上一有效锁文件；恢复成功率以明确的故障用例集为分母。
- 安全性：生成内容必须经过 HTML 编码、安全 URL 协议限制、路径规范化、资源 allowlist。
- 可用性：本地单机生成场景优先约束失败恢复与可离线交付，不无依据提出 99.99% 的远程可用率。

## 3. 需评审确认项目

实际基准硬件与规模、Token 统计范围、允许的不同操作系统版本、组件许可证归档方式，以及组织的日志留存策略。
