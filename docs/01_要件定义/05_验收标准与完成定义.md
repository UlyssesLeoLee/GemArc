# 受入基准与完成定义

> 文档编号：ACC-001 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 验收层级

- A-01 输入与证据：来源完整、无不明授权访问、未知事实不伪造。
- A-02 统一模型：ID 全唯一，所有边引用有效；跨维无事实冲突。
- A-03 网页交付：五维按可用数据渲染，`index.html` 存在，多标签页原型存在。
- A-04 高维行为：4D Case 可暂停/回放；5D 按规则重新计算，不用视觉效果替代推演。
- A-05 技术质量：NFR 指标有可复现的环境、输入和自动/人工证据。
- A-06 许可证与安全：每项可分发第三方资产有声明，禁止未经批准写入。
- A-07 可移植性：无 MCP Client 时可访问交付网站；需本地 HTTP 时带手顺。

## Definition of Done（DoD）

每项变更按次序完成：`需求/设计更新→代码实现→UT 设计及执行→IT/ST 回归→文档与资产锁定`。需保存运行日志、覆盖率、构建锁、签核记录。未执行的测试不得被填写为通过。

## 正式交付门槛

所有 P0 功能符合验收、重大缺陷归零、风险批准、许可证审查完成、用户确认。没有签核记录时只可标记“准备评审”，不可标“生产可用”。
