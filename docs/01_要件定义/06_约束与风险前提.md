## 业务与技术约束

- 不强行声明所谓 IPA 认证、必选 12 View 或数学意义的五维坐标。
- 真实系统事实来源优先于示意与其他参考仓库，参考仓库只借鉴视觉/技术方案。
- 保持现有脚本、Viewer、测试与 Skill 的迁移路径，禁止无理由整体重写。
- MCP 工具不得直接承诺未经许可的外部操作；Components 分发前查许可证。
- 默认中文，可通过配置切换日/英。翻译不改变稳定 ID、代码路径、证据状态。
- 逻辑左手坐标系要求转换至 Three.js 使用的实际世界坐标约定，所有拾取与正交投影必须一致。

- P-01 使用者能提供目标仓库访问授权及必要设计文档。
- P-02 离线交付目标不等于浏览器 `file://` 可读取全部 ES Modules；需要时提供 local HTTP 启动器。
- P-03 4D/5D 如缺少真实事件和约束，只能输出显式假设模拟。
- P-04 大型模型需按聚合/LOD 分组，不能保证所有节点同时全量渲染可读。
