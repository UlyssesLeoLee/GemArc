## 资产分类

| 类别 | 代表组件 | 主要使用方 | 约束 |
|---|---|---|---|
| 页面壳 | index、导航、侧栏、标签页 | 所有维度 | 布局与焦点模型统一 |
| 2D | InfiniteCanvas、GraphNode、GraphEdge、MermaidPane | 2D/原型 | 点击节点与边均有详情 |
| 3D | GemMesh、Room、Floor、Relation3D、AutoLabel、Camera | 3D | 标签自动跟随摄像机、无关项退避 |
| 4D | EventTimeline、StateMachine、Playback、CaseSelector | 4D | 每帧关联事件/状态，不纯装饰 |
| 5D | CompositionGraph、Intervention、ImpactDiff、CausalEvidence | 5D | 每一推断有模型类型和证据级别 |
| UX | PrototypeTabs、Hotspot、PropertyInspector、ToolPalette | 原型 | Konva 多标签页，支持编辑与链接 |
| 共享 | i18n、DesignTokens、Breadcrumb、SelectionStore | 全站 | 稳定 ID，切换维度主体一致 |

## Registry 检索契约

组件必须有 `id/version/semanticRole/dimensions/inputSchema/outputEvents/dependencies/license/compatibility/tests`；禁用无已知许可证的依赖。AI 不应直接收到全部 Runtime 源码，而应先收到轻量 manifest 和参数契约。

## 视觉质量标准

- 宝石形状表示类型、颜色表示状态或领域，两者不冲突；不能让随机亮度代表额外语义。
- 2D/3D 边有可读名称、方向、关系类型，自动避让与必要的局部聚焦。
- 用户选中节点或边，非关联对象变暗/退避；保持空间记忆，不重排全部架构事实。
- 每个 View 6–18 个关键节点为推荐信息密度，不构成硬限制；大图做聚合/分层。
- 不允许以相机旋转、炫光或动态粒子替代新增信息。

## 升级策略

锁定 Schema、组件版本、Runtime 哈希。升级须经兼容矩阵与快照测试；重大版本提供转换报告和回滚点。
