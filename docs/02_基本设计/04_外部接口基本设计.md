## MCP 工具（公开边界）

| Tool | 读取/写入 | 输入类别 | 返回 |
|---|---|---|---|
| `gemarc.inspect` | R | sourceRef/scope | evidenceSummary + warnings |
| `gemarc.plan` | R | projectId/intent | plannedViews + constraints |
| `gemarc.assets` | R | query/capabilities | manifests + compatibility |
| `gemarc.init` | W | targetPath/templateRef | workspaceId + lock |
| `gemarc.model` | W | patch/import/source | modelVersion + diagnostics |
| `gemarc.validate` | R | modelRef/policy | report + exitStatus |
| `gemarc.build` | W | modelRef/outDir/viewPlan | buildId + artifacts |
| `gemarc.simulate` | R | scenarioRef/interventions | trace + outcomes |
| `gemarc.verify` | R | buildRef/testPlan | testReport + failures |
| `gemarc.diff` | R | baselineRef/targetRef | semanticDiff + impactSet |
| `gemarc.export` | W | buildRef/exportKind | manifests + checksums |

## Resources / Prompts

- Resource：`gemarc://schemas/{version}`、`gemarc://components/{id}/{version}`、`gemarc://presets/{name}`、`gemarc://guides/{topic}`。如 URI 不存在应返回明确错误，禁止动态访问任意文件。
- Prompt：`generate_5d`, `review_architecture`, `update_incrementally`, `explain_causality`；Prompt 不可执行文件写入，操作仍经 Tool 授权。

## 协议约束

以 MCP 2026-07-28 为目标：无会话核心、请求 `_meta`、`server/discover` 能力发现；适配旧 Client 的兼容逻辑必须独立模块。stdio 与 Streamable HTTP 的版本兼容性在 IT 测试确认，不使用未协商字段。

## 错误约定

`GEMARC_{DOMAIN}_{NNN}`，例如 `GEMARC_MODEL_001` 缺少引用、`GEMARC_AUTH_001` 输出不在白名单。工具结果需含 `status`, `diagnostics[]`, `artifactRefs[]`, `schemaVersion`；MCP 传输错误与业务验证失败分开表达。
