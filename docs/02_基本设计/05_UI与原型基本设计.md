## 显示与布局原则

- 工具栏组件化，类似轻量图形编辑器，默认收起不常用工具。
- 标签自适应视角：通过 Billboard/Screen-space 检测避免遮挡；Edge 名称在路径上多视角适配。
- 视觉语义优先使用形状 + 文本 + 色彩冗余编码，避免仅靠颜色传递状态。
- 聚焦后不相关节点退避但不丢失拓扑；恢复总览时平滑回到稳定布局。
- 适配桌面 1440x900、1920x1080 和低分辨率笔记本；交互区域提供键盘替代方案。

## 状态隔离（重要）

`GlobalState(selectionId, language, activeDimension)` 与 `PerDimensionState(camera, filters, time, intervention)` 两级状态；2D 事件绑定须幂等和自动解绑，防止重复订阅造成动画速度加快。
