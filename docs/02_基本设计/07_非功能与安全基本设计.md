## 安全边界

`用户授权空间 → MCP 入口 → 受控源读取 → 模型/组件编译 → 临时输出 → 校验 → 原子发布`。

- 来源隔离：README、注释、网页和用户内容均视为数据；禁止提取其中的“忽略之前指令”等文本当成新权限。
- 文件隔离：路径规范化后必须落在允许根目录内；拒绝符号链接逃逸、UNC 越界和 `../` 穿越。
- 组件隔离：第三方组件未被批准时禁止执行；固定依赖版本、许可证扫描、供应链哈希校验。
- 浏览器安全：HTML 安全转义、禁用 `javascript:`、静态资源 CSP、安全的 URL allowlist；离线不降低安全检查。
- 远程适配：Streamable HTTP 采用明确认证、短期令牌、审计日志；本地 stdio 无须暴露公网接口。
- 权限控制：inspect/validate 是只读；init/build/model/export 改变文件必须检查作用域与用户授权。

## 运维与性能

- 指标：处理的文件数、模型节点/边数、构建阶段耗时、组件缓存命中率、验证错误数、模拟事件数。
- 隐私：日志默认不存原始私有源码、凭据与个人信息；仅记录必要位置、校验摘要和错误码。
- 失败重试：Build 采用临时目录，验证成功后原子切换指向；失败保留上一个可用版本。
- 用量控制：限制最大文件量、图节点数、关系数、场景事件数、模拟迭代次数与导出体积。
