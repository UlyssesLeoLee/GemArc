# 部署与运行方式基本设计

> 文档编号：BD-008 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 支持形态

1. **Local MCP/stdio**：由 AI 客户端启动；可访问经授权的本地项目，默认非网络服务。
2. **Remote MCP/Streamable HTTP**：可选部署，须显式认证、租户隔离和速率限制。
3. **CLI/CI**：无需 MCP 客户端即可执行 inspect/build/verify；共用 Core。
4. **独立 Viewer**：静态资源打包输出；离线使用时若浏览器限制 `file://`，提供本地 HTTP 启动手顺。

## 构建环境

- Node.js/TypeScript 栈作为目标架构建议；历史 Viewer 依赖 Three.js 0.180.0 + Vite 7.1.10（仓库静态核对），不能将该版本号自动视为最终依赖锁。
- 第三方 Graphology、Dagre、Konva、Dexie 为拟集成项，打包前复核实际许可证、版本与安全性。
- 不允许运行时从 CDN 下载必须资源作为离线交付的唯一方式。

## 发布/回滚

`validate → test → build → security/license audit → signoff → export → checksum`。每次发布记录 SHA、组件锁版本、NFR 测试环境、遗留缺陷和回滚包位置。
