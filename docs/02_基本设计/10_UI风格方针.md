# UI 与三维风格方针（宝石主题）

> 文档编号：BD-010 ｜版本：1.0 ｜日期：2026-11-04 ｜状态：设计基线（本次已随代码落地）  
> 产品：GemArc MCP — 多媒体文档脚手架  
> 关系：本文是 BD-005《UI、交互与原型基本设计》的风格细则。BD-005 已经写下「3D = 楼层/房间/宝石/关系」，本文把这句话变成可验收的规则；两者冲突时以本文为准。

## 1. 立意：宝石是被切割过的结构

GemArc 的名字里有一个 Gem。宝石之所以是宝石，不是因为它有颜色，而是因为它**被切割过**：它同时具备秩序（对称的面）与光（棱线上的高光）。所以本方针不是「把界面做成宝石的样子」，而是：

- **界面像切面**：信息被切成边界清楚的面，面与面之间是棱线，不是阴影堆叠。
- **三维像晶体**：实体是被打磨过的半透明晶体，棱线比晶体主体亮；关系是穿过它们的光线。
- **光要克制**：宝石的美来自暗场里一小片高光。大面积高光会让水晶变成塑料。

一句话方针：**暗场、切面、亮棱、少量高光；颜色只编码事实，不负责好看。**

## 2. 五条信条

1. **语义优先，装饰为零**：每一个可见元素都必须对应模型里的一个事实。无法对应事实的装饰一律不做。
2. **颜色是编码，不是修饰**：同一颜色在站点与三维场景里必须指同一件事。颜色永远配形状或文字，不单独承载事实。
3. **切面而不是阴影**：层级用 1px 亮棱线与底色差表达，不用多层投影堆出体积感。
4. **静止即静止**：没有自转、没有呼吸、没有循环动画。场景只在读者操作时变化。
5. **可读性高于气质**：正文对比度不低于 4.5:1。任何「晶莹」处理不得压住文字与数据。

## 3. 色板（唯一色源）

站点与三维场景共用同一组令牌。令牌名写在 CSS 变量里，三维场景在 JavaScript 里使用同名常量。

| 令牌 | 值 | 用途 | 禁止 |
|---|---|---|---|
| `--gem-void` | `#06090e` | 最暗的底色（三维场景背景、页面外缘） | — |
| `--gem-bg` | `#0b0f16` | 页面底色 | — |
| `--gem-panel` | `#111823` | 面板、顶栏、检查器底 | — |
| `--gem-facet` | `#1b2635` | 卡片底、分隔面 | 承载正文 |
| `--gem-rim` | `#2c3d52` | 棱线、边框、分隔条 | — |
| `--gem-ink` | `#e6eef7` | 正文 | — |
| `--gem-muted` | `#93a6bd` | 次要文字、注释 | 承载正文 |
| `--gem-aqua` | `#6fe3ff` | 主强调：可交互、当前选中、坐标轴 X | 大面积背景承载文字 |
| `--gem-violet` | `#b78cff` | 次强调：坐标轴 Y、辅助序列 | 同上 |
| `--gem-topaz` | `#ffc46b` | 坐标轴 Z、提示 | 同上 |
| `--gem-emerald` | `#6bd68a` | 已确认、正常、通过 | 同上 |
| `--gem-ruby` | `#ff6b8a` | 错误、阻断、越界 | 同上 |

规则：

- 高饱和色只出现在**边框、图标、轴、光棱、状态点**上，正文永远用 `--gem-ink` / `--gem-muted`。
- 强调色一次只表达一件事（可交互 或 当前选中），不混用。
- 三维场景的实体颜色来自**类型**，来自一组固定色（见 §4.3），且必须与实体类型的语义一致，不得按选中状态改色。

## 4. 三维材质规则

### 4.1 几何

- **实体 = 晶体**：多面体（切角立方体或八面体），不用球。球没有棱线，就不是宝石。
- **容器（楼/层/房间）= 线框**：只画棱线，不画实心体；楼层可有一块半透明底板。
- **关系 = 光线**：细管、半透明、未选中时更淡。信任边界一类用分段几何表示虚线，不得用贴图。

### 4.2 晶体主体与棱线

- 实体主体：半透明（不透明度 0.45–0.7），低粗糙度、低金属度。
- 实体棱线：**始终可见**，亮度高于晶体主体；选中时棱线提到最亮并加内发光，主体不透明度略微提高。
- 棱线是宝石与普通方块的区别。没有棱线的半透明方块是玻璃，不是宝石。

### 4.3 类型色板

三维实体按类型取色，未登记的类型使用统一的中性灰（不与任何已登记类型同色）：

| 类型 | 颜色 | 类型 | 颜色 |
|---|---|---|---|
| system | `#6fb3ff` | actor | `#ff9a8b` |
| service | `#ffc46b` | gateway | `#ffd166` |
| module | `#9ad36f` | plugin | `#c8f06a` |
| process | `#d59bff` | security | `#ff7b9c` |
| data | `#7fe3d4` | operations | `#7fd1ff` |
| database | `#7fb0ff` | runtime | `#c9d1d9` |
| storage | `#c0a6ff` | external | `#8a94a6` |

### 4.4 坐标轴

- 三根轴各占一种宝石色：X=`--gem-aqua`、Y=`--gem-violet`、Z=`--gem-topaz`。
- 每根轴画成一根光柱，刻度处有一道短横，刻度值是标签。
- **轴值是类别不是度量**：不得把顺序型数值伪装成可比较度量；一根轴只有一个取值时，必须显式报告「该轴不提供独立信息」。

### 4.5 灯光

- 一盏环境光 + 一盏主光 + 一盏冷色补光，比例约 0.66 / 0.80 / 0.30。
- 背景用 `--gem-void`，让棱线自己发亮。禁止过曝光晕、禁止体积雾、禁止地面反射。

### 4.6 三维禁止项

- ❌ 持续自转、呼吸缩放、粒子、拖尾。
- ❌ 彩虹渐变贴图、噪声贴图、扫描线。
- ❌ 用三维装饰承载模型里没有的事实（假楼层、假房间、假设备）。

## 5. 界面规则

| 元素 | 规则 |
|---|---|
| 页面底 | `--gem-bg` 纯色；三维画布内部用 `--gem-void` |
| 面板 / 顶栏 | `--gem-panel` 底 + 1px `--gem-rim` 下棱线；不使用多��投影 |
| 卡片 | `--gem-facet` 底 + 1px `--gem-rim` 边 + 极轻内高光（1px，不做投影堆叠） |
| 按钮 | 默认透明底 + 1px `--gem-rim` 边；悬停时边变 `--gem-aqua`；按下时底变 `--gem-facet` |
| 当前选中 | `--gem-aqua` 的 1px 边 + `--gem-aqua` 文字，不换背景大面积上色 |
| 焦点 | 2px `--gem-aqua` 外轮廓（`outline`），不得移除 |
| 分隔条 | 常态不可见，悬停/拖拽时显出 2px `--gem-aqua` |
| 状态徽记 | 圆点 + 文字；已确认 `--gem-emerald`，提示 `--gem-topaz`，错误 `--gem-ruby` |

- **磨砂玻璃只允许出现在外壳层**（顶栏、侧栏、检查器），且必须有实体底色衬托；正文区、数据表、代码块一律不透明。
- 圆角统一 6px（小控件 4px），大块面板 8px。

## 6. 动效

| 场景 | 规则 |
|---|---|
| 悬停 / 聚焦反馈 | 80–120ms，只改颜色与棱线亮度，不做位移与缩放 |
| 选中 | 即时切换，不做渐变动画 |
| 三维场景 | 静止即静止；只有相机与读者操作引起的变化 |
| 面板展开 | ≤160ms，且不改变主栏的最小宽度下限 |

禁止：循环动画、进场逐项淡入、入场自动旋转。

## 7. 可访问性

- 正文对比度 ≥ 4.5:1，次要文字 ≥ 3:1。
- 颜色不单独承载事实：状态永远是「颜色 + 形状/文字」。
- 所有可拖拽分隔条可聚焦、可键盘调节（当前宽度以 `aria` 数值属性或可见文字给出）。
- 三维拾取失败时必须显式说明，不得用二维图伪装三维。

## 8. 反面清单

- ❌ 玻璃拟态压在数据表或代码块上。
- ❌ 霓虹粉紫渐变铺底、彩虹色文字。
- ❌ 三维物件持续自转或呼吸。
- ❌ 用颜色承载事实、却没有形状或文字冗余。
- ❌ 圆角 + 多层投影堆叠出体积感。
- ❌ 为了「像宝石」而牺牲正文可读性。

## 10. 验收口径

一条产出算「符合本方针」，当且仅当：

1. 三维场景里**没有**持续动画，实体**有**可见棱线，关系是细管而不是实心杆；
2. 场景背景是 `--gem-void`，界面底色是 `--gem-bg`，两者肉眼可分；
3. 页面上每一种强调色都能对应到「可交互」或「当前选中」之一；
4. 正文没有任何一处压在半透明层上；
5. 同一个模型渲染两次，场景**逐像素一致**（确定性是宝石主题的一部分：同一颗宝石，切面必须一样）。
