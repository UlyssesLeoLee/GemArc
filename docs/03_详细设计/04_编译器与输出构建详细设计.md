# 编译器阶段与站点构建详细设计

> 文档编号：DD-004 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 编译阶段

1. Load Sources（仅允许范围内文件）
2. Normalize（UTF-8/NFC/稳定路径标识）
3. Extract & Trace（事实候选与证据）
4. Validate Schema（字段/枚举/ID/跨对象约束）
5. Resolve Assets（组件注册检索、许可、版本锁）
6. Generate ViewModel（1D–5D/Prototype 的独立投影）
7. Emit（固定 Runtime + 项目数据 + 允许的扩展组件）
8. Verify（文件、界面、逻辑/模拟、许可证）
9. Publish（原子切换到最终目录，写 manifest/sha）

## 不变量

- 编译绝不修改源仓库；目标目录受限于 authorizedRoot。
- 输出不能只有首页，缺失被要求维度须出具不可用原因。
- 不允许随机生成不稳定的节点 ID；确定性信息不依赖系统时间。
- 已存在非空输出目录默认拒绝覆盖；允许 `replace-atomic` 时仍保留上一代校验过的构建结果。

## 规范化散列

`BuildKey = SHA256(NormalizedModel + LockManifest + BuildOptions + ToolVersion)`，其中排除仅用于显示的构建时间。对字符串排序、数字/空值编码定义一致的 canonical JSON 规则；普通 JSON dump 不自动等同于跨语言规范化标准。

## 产物清单

见 `../08_附录/examples/output-layout.txt`。产物 `build-manifest.json` 至少列出文件相对路径、SHA256、来源 Model 版本、组件锁与验证结果；各维共享 Runtime 而非各目录复制源码。
