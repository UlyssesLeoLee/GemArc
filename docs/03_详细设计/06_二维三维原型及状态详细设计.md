# 二维/三维、Konva 原型与状态一致性详细设计

> 文档编号：DD-006 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## Viewer Runtime

- 2D：Graphology 维护图运算与关系查询、Dagre 作布局（按图类型可替换策略），SVG/Canvas 展示；浏览器交互缓存由 Dexie 提供可丢弃的状态缓存。
- 3D：Three.js Geometry + Raycaster + Camera Controls + Label Layer；场景逻辑坐标统一左手系，经 TransformAdapter 映射到 Three.js 渲染计算用世界坐标。
- Prototype：Konva.js 管理可选中/可编辑元素，多标签页共用标准导航和热点绑定。
- 通用：由 `SelectionStore` 持有 `entityId`，各维 `DimensionState` 独立管理 focus/camera/filter/timeline/intervention。

## 交互事件与去重

事件注册使用唯一 namespace+handler ID：重复装载/销毁时事件数不增长；切换视图清理动画 frame、DOM listener、Graph subscription、Timer。对 EventBus 添加同源事件去重 token，避免多重监听加速。

## 自动标签方案

- 2D：基于边方向、标签尺寸、碰撞评分避让；避免遮住目标 Node 和箭头，必要时用 hover 显示完整 label。
- 3D：节点与边标签 billboard 但锚点按相机夹角调整，优先清晰易读；详细文字在侧栏显示。
- 关系线可点击：Edge ID 与其几何 segment/picking proxy 显式绑定，点击边不得错误选中相邻节点。

## 跨维切换

切换仅传播 `entityId`，绝不传播 4D 当前逻辑时间或 5D 干预至 2D/3D 模型事实。对应维度无法表示该节点时显示定位说明，不创建虚构节点。

## 浏览器禁用 WebGL

如 WebGL 初始化失败，明确呈现 `3D 不可用` 并允许 2D；禁止 CSS 伪 3D 冒充成功。静态资源加载失败必须显示真实失败信息。
