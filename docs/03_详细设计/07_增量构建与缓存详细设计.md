# 增量编译、缓存与模型差异详细设计

> 文档编号：DD-007 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 依赖图

`source files → evidence objects → semantic nodes/edges/rules → views/scenarios → component instances → compiled assets → export packages`。

## 变更算法

- Diff 输入：前版输入哈希、事实索引、当前 Schema、组件 Lock。
- 变更种类：ADD/REMOVE/UPDATE/RENAME/UNKNOWN；内容变化按 ID 和语义字段比较，不按视觉坐标比较。
- 影响传播：沿依赖图查找受影响视图、动态 Case、文档/测试；仅重建受影响投影。
- 失效边界：组件 major 升级或 Schema major 更新默认使所有相关 View 重新验证，必要时全量构建。
- 缓存有效性：Key 包括模型 Canonical Hash、插件版本、语言、渲染配置和安全策略版本。

## 合并冲突

并发 Agent 更新模型使用 `expectedVersion` CAS；冲突返回 `GEMARC_MODEL_CONFLICT`，附涉及的 Node/Edge/Rule ID。不得默认最后写入者胜。

## 失败恢复

阶段产物暂存到 `.buildtmp/{buildId}`；校验后原子切换，失败标记 `FAILED` 与诊断，原有效包不被覆盖。
