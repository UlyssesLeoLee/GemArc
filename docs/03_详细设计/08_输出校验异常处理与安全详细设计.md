## 错误登记

| 编码 | 触发 | 级别 | 处理 |
|---|---|---|---|
| GEMARC_SOURCE_001 | 来源不可读取 | ERROR | 中断事实确认；允许用户更换来源 |
| GEMARC_MODEL_001 | Node/Edge 引用无效 | ERROR | 阻断构建 |
| GEMARC_MODEL_002 | 相同 ID 冲突 | ERROR | 返回冲突实体清单 |
| GEMARC_ASSET_001 | 组件版本不兼容 | ERROR | 更换版本或显式迁移 |
| GEMARC_LICENSE_001 | 许可证未知/禁止分发 | ERROR | 不打包该组件 |
| GEMARC_AUTH_001 | 越权目录访问 | ERROR | 拒绝操作并审计 |
| GEMARC_CAUSAL_003 | 无依据输出确定性因果 | ERROR | 降级为 UNKNOWN/HYPOTHETICAL |
| GEMARC_SIM_002 | 事件循环上限 | WARNING/ERROR | 输出 INDETERMINATE 而不继续运行 |
| GEMARC_VIEW_003 | 标签过密 | WARNING | 提示聚合/视图重分解 |
| GEMARC_IO_009 | 原子发布失败 | ERROR | 恢复旧构建 |

## 验证顺序

静态 Schema→语义→来源与权限→组件许可→模型一致性→行为与测试→UI/视觉→导出完整性。执行每一步均有机器可读报告；错误与警告不能仅显示在 AI 自然语言里。

## 安全策略设计

- 绝对路径先规范化，检查符号链接的最终目标；禁止 TOCTOU 时须在打开后验证文件对象属于授权根。
- HTML 注入源文本必须进行上下文适当转义；MD 链接协议白名单；禁止自带执行脚本的外部数据默默进入 Runtime。
- MCP 远程输入需限速、身份鉴别、请求体大小上限、CPU/内存/时间预算。
- 不复制 Git 凭据到交付包；logs 仅保留路径哈希及可安全公开的定位信息。

## 审计日志

结构 `{traceId, tool, action, authorizedRootHash, inputDigest, result, errorCode, durationMs}`；不得记录 Secret、未经授权源码全文。
