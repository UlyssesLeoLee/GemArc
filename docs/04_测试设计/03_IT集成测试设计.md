## 特别关注

- MCP stdio 与 HTTP 的鉴权/协议失败须与业务校验失败区分。
- Model 的 confirmed 证据从 Viewer 详情面板可点击反查；未知和假设必须可见。
- 组件 Registry 返回版本锁并贯穿编译/导出；禁止构建器重新解析未锁版本。
- 将不同模型产生的相同组件实例放到相同 Viewer，接口不因业务差异破坏。
