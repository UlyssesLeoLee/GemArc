## 可靠性及兼容性

- 浏览器 WebGL 关闭：明确告知 3D 失败，2D 正常展示，不伪装 3D。
- 本地 `file://` ES module 被限制：提供受控本地 HTTP 手顺并核查资源离线。
- 构建中断：旧版本有效包仍完整，可重试。
- Windows/macOS/Linux 对路径及权限边界分别测试。

测试执行环境、测量原始数据和日志在执行阶段补充；所有指标均待测。
