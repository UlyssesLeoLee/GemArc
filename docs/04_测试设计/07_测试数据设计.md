| 数据集 | 数据特性 | 用途 | 来源属性 |

| DATA-001 | 2 Node/1 Edge + View + Evidence | 最小有效模型 UT | 合成数据、明确 illustrative |

| DATA-007 | GemArc 旧架构 JSON 样例 | Schema 迁移兼容 | 当前仓库 assets/examples |
| DATA-008 | 两个真实可审计业务仓库 | 复用率与事实追溯 | 执行阶段由负责人授权 |

## 数据隔离

真实源项目不得存放用户私钥或个人敏感数据到测试附件。只需记录来源 commit 和内容散列；任何合成数据必须在 Viewer 标明 illustrative。

## 重放

Case 的 `seed`、`logicalClock`、`rulesVersion` 和 `maxEvents` 必须固定；运行结果与快照以 Canonical JSON 比对。测试数据不包含实际用户业务事实时，不得将 Case 结果当作生产证明。
