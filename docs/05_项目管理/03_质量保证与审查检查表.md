# 质量保证与分阶段审查清单

> 文档编号：QA-001 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 需求评审检查点

- 所有 FR/NFR 有唯一 ID，业务范围/排除项明确。
- NFR 的指标可量测，门槛注明拟议或实测。
- 业务目标与 UAT 映射完整；假设与未决事项单列。

## 基本设计评审检查点

- 系统边界、模块责任、接口、权限/信任域、视点及数据模型有一致来源。
- View 不与维度混淆，2D/3D/4D/5D 全部引用相同实体。
- 错误恢复、日志、离线环境和发行许可受设计控制。

## 详细设计评审检查点

- 工具接口有 input/output Schema 与错误码；Schema 有外键/枚举/版本策略。
- 构建器支持锁定版本、生成临时目录、原子发布与回滚。
- 5D 有可审计规则、事件上限和结果证据分类。
- 图形、标签、坐标和交互原型所有关键行为有对应测试。

## 测试评审检查点

- 每条 P0 FR 至少对应 UT/IT/ST，NFR 有性能/安全/兼容性指标。
- 执行报告与设计书分离；不虚构通过记录。
- 代码覆盖率、风险、缺陷与 UAT 签核形成正式发布闸门。

## 裁剪/偏离登记

IPA/ISO 是指导性参考而非此项目自动认证。实际项目不适用的要求须记录不适用理由和审批结论；不能简单删除风险高的章节以掩盖缺口。
