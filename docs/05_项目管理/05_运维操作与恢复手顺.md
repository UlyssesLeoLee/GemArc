# 运维、故障恢复与清理手顺

> 文档编号：OPS-001 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 正常操作

1. 审核输入源和输出根；核对当前源的 commit/ref 与授权。
2. `inspect → model → validate`；有错误先修模型，不允许绕过 strict gate。
3. `assets → init → build`，固定模板、Schema 与组件锁。
4. `verify` 查看质量报告；未通过不得发布为正式交付。
5. `export` 输出 ZIP；检查 SHA256、LICENSE、Notice、manifest。

## 事故恢复

- 构建失败：保留 last-known-good 目录，禁止半完成目录被标记为发布版。
- 输出目录不可写：先确认授权和 ACL，不建议默认管理员权限运行。
- 浏览器 WebGL 不可用：展示 2D 与错误说明，查驱动和 WebGL 功能，不以 CSS3D 顶替。
- Event Queue 超限：中止 Case、保存 trace、标 `INDETERMINATE`。
- 组件更新破坏兼容：回滚锁文件到上一经过验证的版本。

## 日常检查

依赖漏洞与许可证、磁盘临时目录、缓存清理、构建失败率、隔离日志中的异常工具操作、版本兼容性。

## 数据保留

模型与签核记录须按项目计划保留；临时缓存允许清理，但不得删除唯一证据来源。具体保留年限由项目组织规定，不能虚构统一法定年限。
