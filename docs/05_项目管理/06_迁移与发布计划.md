# 迁移与发布计划

> 文档编号：REL-001 ｜版本：1.0 ｜日期：2026-10-25 ｜状态：设计基线（待评审）  
> 产品：GemArc MCP — 5D Design Scaffolding & Architecture Compiler  
> 说明：本文件为目标设计，不代表目标功能已实现或已测试。

## 从现有 GemArc 仓库迁移

1. 冻结现有 `main` Commit 和 Viewer 构建样例；获取现有测试真实通过基线。
2. 在不改写旧脚本行为的前提下，为 `scripts/validate.py` 和 `build.py` 建立 adapter。
3. 设计新 Schema 的旧数据迁移器，保存旧数据与迁移报告，不覆盖原模型。
4. 提取 Viewer 的共通组件，建立 Registry/锁版本；保留现有 `three` 和 Vite 的兼容性测试。
5. 新增 MCP 层调用已有 Core/Adapter，而不是复制旧 Validator 逻辑。
6. 逐步新增 Graphology/Dagre/Konva/Dexie、4D/5D，所有新能力需有真实用例测试。
7. 对现有示例、不同项目样例、三语言进行对照测试；达标后切换默认路径。

## 回滚触发

任一 P0 缺陷、资产许可问题、权限越界、模型事实丢失、输出不可重建 → 回滚到上一个发布目录/lock；不得修改源仓库以掩盖问题。

## 发布工件

`source-commit, schemaVersion, registryLock, buildManifest, docsVersion, testReport, licenseManifest, releaseChecksum, knownIssues, approval`。

## 阶段里程碑

P1（资产/模型基础）；P2（MCP/Viewer/编译闭环）；P3（4D/5D）；P4（联测与受入）；时间与责任人待正式项目计划确认。
