# 格式：.atl 行（put 接收切片文本）

- 第一行 `#atlas 1`（to-be 项目写 `#atlas 1 mode=tobe`）。`//` 开头是注释行。UTF-8。
- 一个段以表头 `## name: col | col | opts` 开始。表头必须原样抄写，列顺序固定。
- 一行里 `|` 分隔的文本单元格数量必须与表头一致，单元格不能为空；之后是唯一一个选项单元格，由 `key=value` 组成（没有选项要设就整个省掉这个单元格：`~` 只用于取 `@set` 默认值的文本单元格，不能当空选项单元格）。值可以是裸词、"带引号字符串"、{json} 或 [json]；列表用逗号连接 id（`ev=A,B`）。文本里的字面 `|` 写成 `\|`。
- `@set k=v` 给本段后面的行设标量默认值（`@set room=rm.a kind=Module`）；单元格写 `~` 取默认值；`@set k=` 清除。不要对 ev、nodes、edges、req 这类列表用 `@set`。
- 边列表写完后写 `@final edges`（它放行等待边的检查）。`@pending id,id` 用来压住有意的前向引用（很少需要）。
- 文本单元格里出现像选项的内容（`word=word`）是 ST-006：给该单元格加引号。含 ASCII 引号的文本单元格必须是一个完整的 JSON 字符串；要在 policy 的 text 里引用用户原话，用 '...' 或「...」。选项不能重复位置单元格（nodes 行写 `name=` 是 ST-007）。
- 有语法缺陷的行会被丢弃并报告；切片的其余部分照常读取。
